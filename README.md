# Farm Money Tracker 🌱

เว็บแอปสำหรับช่วยเกษตรกรบันทึกและติดตามรายรับ–รายจ่ายของสวน พร้อมดูสรุปต้นทุน รายได้ และกำไรได้ง่ายในที่เดียว

ออกแบบให้ใช้งานง่าย ตัวอักษรใหญ่ ปุ่มกดชัดเจน รองรับทั้งคอมพิวเตอร์และโทรศัพท์มือถือ 

## การอัปเดต API

เว็บเวอร์ชันนี้ต้องใช้ `Code.gs` เวอร์ชันเดียวกัน: อัปเดตไฟล์ในโปรเจกต์ Google Apps Script แล้วสร้าง Web App deployment เวอร์ชันใหม่ ก่อนเผยแพร่เว็บที่ build ใหม่ การล็อกอินจะได้ session token ซึ่งมีอายุ 30 วันนับจากล็อกอิน (ไม่ต่ออายุอัตโนมัติ) เก็บฝั่งเซิร์ฟเวอร์ใน Script Properties และฝั่งเบราว์เซอร์ใน localStorage จึงปิดแล้วเปิดเบราว์เซอร์เดิมได้โดยไม่ต้องล็อกอินซ้ำ จนกว่าจะออกจากระบบ ล้างข้อมูลเว็บ หรือครบกำหนด และคำขออ่านหรือแก้ข้อมูลทุกครั้งต้องส่ง token นี้

ตัวกรองรายการใช้วันเริ่มต้นและวันสิ้นสุดแบบรวมขอบทั้งสองด้าน (`startDate`, `endDate`) ในคำขอ `getTransactions` ฝั่ง Apps Script จะคืนเฉพาะรายการในช่วงที่เลือก หากยังใช้ deployment เก่า หน้าเว็บจะกรองเพื่อแสดงผลได้ แต่ยังต้องดาวน์โหลดรายการทั้งหมดจนกว่าจะอัปเดต Apps Script

บัญชีผู้ใช้เก่าในชีต `Users` ยังใช้ได้ แต่ควรเปลี่ยนรหัสผ่านที่ตั้งไว้เดิม โดยเฉพาะบัญชีทดสอบ `admin` หากยังมีอยู่ ฟังก์ชัน `setupSheets()` จะไม่สร้างบัญชีพร้อมรหัสผ่านเริ่มต้นให้อีก

## การโหลดข้อมูล

หน้าเว็บเรียก `getAppData` เพื่อโหลดรายการตามช่วงวันที่และหมวดหมู่ในคำขอเดียว ใช้ผลในหน่วยความจำซ้ำได้ 30 วินาที (สูงสุด 20 คำขอ) และรวมคำขอที่กำลังโหลดเหมือนกัน แคชถูกล้างเมื่อบันทึก/แก้ไข/ลบข้อมูลหรือเปลี่ยน session ไม่เก็บข้อมูลบัญชีลง localStorage เพิ่มเติม การแก้ใน Google Sheets โดยตรงให้กด “รีเฟรชข้อมูล” หรือรีโหลดหน้าเว็บ ไม่มีการโหลดใหม่เมื่อสลับแท็บ เปลี่ยนวันที่รอ 250 ms เพื่อรวมการเปลี่ยนที่ติดกัน และหลังบันทึกใช้ข้อมูลที่บันทึกสำเร็จปรับหน้าจอโดยไม่ดึงทั้งชุดซ้ำ

อัปเดต Apps Script deployment พร้อมหน้าเว็บเพื่อใช้ endpoint ใหม่นี้ หากยังเป็น API เก่า เว็บจะใช้สอง endpoint เดิมชั่วคราว ฝั่งเซิร์ฟเวอร์ยังอ่านแถวทั้งหมดจากชีต แต่สร้างผลลัพธ์เฉพาะช่วงที่เลือกและอ่าน timezone เพียงครั้งเดียวต่อคำขอ
